Project plan

This website was built for the first assignment in Introduction to Web Technologies. I chose Dostyk restaurant because it is a real place in Karaganda. The pages use local information, real prices, contact details, and photographs instead of placeholder content.

The site uses plain HTML. It has no hosting, domain name, CSS, JavaScript, templates, or frameworks. Each file can be opened directly in a browser.

Semantic choices

I used <section> for related content, <figure> for captioned images, and <address> for contact information. These choices keep the structure meaningful and avoid using div where a real HTML element is better.

Validation notes

I can check the repository with git status and test each page with the W3C validator. A valid file may show Document checking completed. No errors or warnings to show.
