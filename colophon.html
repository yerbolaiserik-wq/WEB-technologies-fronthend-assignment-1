Website Plan and Implementation

This website was made for the first assignment in Introduction to Web Technologies. I chose the real Palauhana cafe in Karaganda because It is my brother's business and the project must use real information from a place that can be visited or contacted. The menu, address, phone number, and working details are written as local project content, not as placeholder text. Every page opens as a local file in the browser, so the site does not use hosting, a domain name, CSS, JavaScript, templates, or frameworks.

While building the pages, I followed the basic HTML document structure: doctype, language, charset, viewport, description, author, unique title, header, nav, main, and footer. I used semantic tags because they explain the purpose of each part to the browser and to the reader. The menu page uses a real table, and the order page has a form that shows the planned data fields even though there is no server yet.

Semantic Choices

I used <section> for groups of related content, <figure> to keep an image together with its caption, and <footer> for contact and copyright information. These choices helped me avoid using div where a meaningful HTML element was better.

Code and Validation Notes

When I check the site, I first review the repository with git status. Then I test each HTML file with the W3C validator. If the page has no errors, the validator can return a message such as Document checking completed. No errors or warnings to show.
